# 🗒️ 사용 방법
- 깃 서브모듈로 사용
- 버전별로 구분 되어 있음
<details>
<summary><h3>추가 명령어</h3></summary>
  
  1. 프로젝트의 루트로 이동
  2. git submodule add https://github.com/Lume-uta/Unity_Architecture.git 폴더_경로/이름
</details>
<details>
<summary><h3>태그 변경 명령</h3></summary>
  
  1. 서브모듈의 주소로 이동
  2. git fetch --tags
  3. git checkout 태그명
</details>
